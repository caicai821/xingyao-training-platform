# 星耀童行 · 3D 场景辅助训练系统

面向训练指导人员与教育工作者的前端原型，围绕「学员档案 → 能力画像 → 训练目标 → 训练脚本 → 3D 场景生成 → 场景资产」构建完整的辅助训练工作流。

当前阶段聚焦 UI/UX、页面结构、交互流程与模拟数据，**不包含**真实 3D 渲染、场景内部交互、人物动作控制或模型训练。

## 技术栈

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- React Router 7
- Lucide React 图标
- 自研轻量图表组件（雷达图 / 趋势图 / 评分条 / 迷你趋势线）

## 界面设计

- 采用「暖白 + 冰川蓝」视觉体系，搭配薄荷、杏橙、浅紫等低饱和辅助色。
- 工作台首屏使用冰川晶体空间插画（`src/assets/hero-glacier.webp`）。
- 品牌标识采用「星耀童行」圆形亲子星轨徽标（`src/assets/brand-logo.webp`），以深蓝、薄荷绿与金色星芒呼应训练主题。
- 登录页采用暖米白、淡橙与浅紫蓝的治愈系渐变，左侧为家庭陪伴线描插画（`src/assets/login-family.webp`），右侧为半透明毛玻璃登录卡片；登录与注册锁定单屏高度，短屏设备自动压缩次要信息，避免页面滚动。
- 色彩、圆角、阴影、字体层级与背景氛围统一维护在 `src/index.css`；工作台专属组件位于 `src/components/dashboard/`。
- 支持 `prefers-reduced-motion`，并保留键盘焦点与任务行链接等可访问性细节。

## 运行

```bash
npm install
npm run dev
```

默认地址：`http://localhost:5173`

生产构建：

```bash
npm run build
npm run preview
```

> 若 5173 端口被占用，Vite 会自动选择下一个可用端口，请以终端输出为准。

访问 `/login` 可查看演示登录页：通过卡片顶部的悬浮玻璃导航切换「登录 / 注册」；任意账号密码均可登录，也可点击「填入演示账号」快速体验。注册为本地演示流程，完成校验后直接进入演示工作区，不涉及真实身份认证。进入后由右上角账号菜单「退出登录」返回登录页。

## 演示模式与真实 API

- 默认使用 **演示模式**：数据保存在浏览器 `localStorage`，任务状态由模拟服务驱动。
- 在「系统设置」中可切换为 **真实 API 模式**，并配置 API 基础地址、上传地址与请求超时。
- 也可通过环境变量指定默认配置（参考 `.env.example`）：

```bash
VITE_API_MODE=mock
VITE_API_BASE_URL=https://api.example.com/v1
VITE_UPLOAD_URL=https://upload.example.com/v1/files
VITE_REQUEST_TIMEOUT=30000
```

- 页面只依赖 `src/services/contracts.ts` 定义的服务接口，模拟实现与 HTTP 实现分别位于：
  - `src/services/mock/`
  - `src/services/api/`
- 切换服务实现不会改动页面组件。

### 模拟场景任务

提交场景任务后，任务会依次经历「待提交 → 排队中 → 生成中 → 生成成功」状态，页面每 1.6 秒自动刷新进度：

| 时间 | 状态 |
| --- | --- |
| 0–1.4s | 待提交 |
| 1.4–3.6s | 排队中 |
| 3.6–9s | 生成中 |
| 9s 后 | 生成成功 / 失败 |

- 「系统设置 → 演示行为」可开启「模拟场景生成失败」。
- 失败任务可点击「重新生成」体验恢复流程。
- 成功的任务会自动归入场景资产库。

## 主要页面

| 模块 | 页面 |
| --- | --- |
| 入口 | 登录（演示） |
| 概览 | 工作台 |

## 数据关联

```text
学员档案 → 能力画像 → 训练目标 → 训练脚本 → 3D 场景生成任务 → 场景资产
```

- 能力画像必须由使用者确认后才用于训练目标设计。
- 训练脚本需确认后才能创建关联场景任务。
- 场景任务会保存学员、训练目标与训练脚本 ID。
- 场景资产由成功任务自动生成，可在资产库中维护基础信息。

## 演示数据

所有姓名、编号、档案、训练记录与场景均为虚构演示数据。可在「系统设置 → 演示数据管理」中一键重置。

```text
├─ App.tsx           路由与页面结构
└─ index.css         设计令牌与全局样式
```

## 当前边界

- 不实现真正的 3D 场景生成、渲染引擎与场景编辑器。
- 不实现学员身份认证、角色权限与生产级数据安全设施。
- 场景预览均为演示示意，不伪装为实时生成结果。
- 结果引用字段已为未来接入真实服务预留。
